# 操作记录与回放

> 并发、准入和容量口径已于 2026-10-11 同步。完整预算、默认 2／1 与特定 ECS 7／7 的区别见 [并发设计与容量验收](并发设计与容量验收.md)。

每份问卷可在 JSON 顶层设置 `"record_interactions": false`，关闭参与页和图片任务的通用操作轨迹及界面快照。`true` 或省略时开启；只接受布尔值。开关属于冻结版本，已有会话和历史记录保持原设置。关闭时不注册轨迹监听器、不读取布局或编码批次，也不创建／上传 `d-ui-*` 事件。答案修订、封存、设备协变量、实验呈现／作答／反应时间和评分记录仍保留，答案重试机制继续工作。具体配置见 [JSON 问卷与图片包](JSON问卷与图片包.md)。

开启时，参与页和图片任务保存浏览器提供的触摸、鼠标/触笔按下/移动/释放/取消、点击、键盘、输入、焦点和输入法事件。拖动包括浏览器提供的全部合并样本，并保留压力、接触宽高、tilt/twist、修饰键。还包括 beforeinput、compositionupdate、wheel、指针捕获和页面/网络/视口状态变化。copy/cut/paste 只记录操作类型，不读取剪贴板内容。时间使用 `performance.timeOrigin + at`，坐标采用视口内 CSS 像素，键盘事件没有指针坐标。

每次界面变化保存可见元素位置、文字、基础样式、控件值、视口/DPR/滚动信息及图片资源 ID。`rt_ms` 是该题或当前评分项显示后的操作时间；图片任务另有从图片绘制到首次选择、最终提交的反应时间，以及各评分项首次/末次选择时间。旧记录不能补生成未采集的动作。

动作以 `interaction-v1` 批次保存到独立 `d-ui-*` 诊断链；不改变答案链、封存或实验调度。本机 IndexedDB 保存后再补传，服务器原始数据保留。相同界面快照去重，动作不去重；批次限制为 64 条/约 90 KiB，100 ms 刷写。显式页面/刺激快照同步；同 microtask 的普通输入快照请求合并，滚动快照按帧合并并保存 capture 标记。最多 1900 节点且标记截断，单事件仍为 128 KiB预算。本机队列或磁盘写入失败会停止作答并提示恢复，不静默丢弃。较大批次使用可选原生 gzip，原文及 SHA-256 身份保持。详细合同见 [轻量采集与传输](浏览器轻量采集与传输设计.md)。

管理员从“查看答卷与回放（数量）”进入回放页，可以播放、暂停、拖动时间轴、逐动作查看。管理列表只显示具有有效 `interaction-v1` 界面快照的答卷；没有可回放答卷的问卷不显示此入口，答卷结果 CSV 仍包含所有会话。回放使用当时的布局/图片、输入值和触点轨迹重建，JSON 显示每个动作完整字段。CSV 中 `interaction_actions` 包含动作和界面快照，`trial_results` 包含评分反应时间，`reanswer_links` 保存重新作答前后关系。

管理列表每份答卷显示“记录数 · 界面快照数 · 秒作答时长”。时长为该答卷首条至末条操作记录的时间差，与回放时间轴一致，按秒显示、最多一位小数；跨页面使用各批次的 `time_origin + at`。直接读取已有回放索引的首末时间，无需扫描原始轨迹。未完成答卷显示当前已记录的时间跨度，不随管理员查看时间增长；缺少记录时不推算为零。

每份可回放答卷提供“下载本份轨迹 JSON.gz”和“下载离线回放 HTML”。前者是 `session-trajectory-v1`，包含该会话保留的全部 `d-ui-*` 原始 UTF-8、哈希、接收凭证和最新处理状态，包括非规范或被拒绝的证据；不包含凭据或其他会话。后者将同一份 gzip 证据、播放器和引用的图片嵌入一个 HTML 文件，无需登录或联网即可打开。离线播放器校验原文及图片 SHA-256，只播放格式有效的规范事件。HTML 按记录重建界面，不生成视频，不改变原始样本、坐标或时间精度。

单份下载在只读工作线程中生成，同一服务同时生成一份，120 秒超时；繁忙返回 503。JSON 原文上限 1 GiB，HTML 原文上限 128 MiB、图片合计上限 64 MiB，最多 10 万个原始批次。正常完成或连接关闭后立即移除服务器临时文件；异常残留由每日北京时间 00:00 的清理任务移除。原始数据不在清理范围。部署和实测见 [单份轨迹与离线回放](单份轨迹与离线回放-20261016.md)。

在线回放每次读取 20 个批次，并根据 `Accept-Encoding` 使用异步 gzip 无损压缩。压缩同时最多两份响应，不占用数据库写入线程；支持明确拒绝 gzip 的客户端。源内容、批次和游标不变。

回放是软件记录的重建，不是屏幕视频：浏览器之外的动作、未派发的物理采样、系统键盘界面、操作系统渲染与物理显示延迟不在记录中，原生控件和字体换行的视觉表现可能与原设备不同。

2026-10-23 起的新快照使用可选的 `render_version: 2`，保存浏览器测得的逐行文字位置、各边边框和圆角、选中标记伪元素、可见裁剪区域、输入控件类型、文字刺激画布尺寸及页面语言。透明或隐藏内容不绘制；滑块拖动和异步界面变化按帧合并采集，继续沿用原有节点／字节预算及截断标记。旧快照保持可播放，文字采用换行兼容绘制，但无法补回当时没有保存的伪元素和精确行位置。

在线和离线播放器共用同一渲染器。页面快照绘制后缓存，播放帧合成指针轨迹，动作详情最多每 200 ms 更新一次，暂停和逐动作查看时立即显示完整字段。时间轴按实际经过时间定位；图片提前加载并解码，缓存最多保留八项图片资源；画布按查看设备像素密度绘制，最高 2 倍、约 800 万像素。原始动作样本、时间和坐标不变。

“重新作答”创建新会话，并对旧本机会话元信息归档。服务器保留旧答卷，通过不可修改的关联表和 `REANSWER` 标记关联新答卷。新会话使用同一问卷最新版本，前提是知情同意文本相同，否则保留原版本。

纯问卷（没有实验任务组）不限制同时作答名额，也不占用任务名额；带图片或定时任务组的版本满额立即 409，手动稍后重试。服务的 HTTP、数据库和资源保护仍生效。

服务器采用单份原文与 gzip 无损压缩存储，读取、回放及完整证据导出时按原始字节和 SHA-256 解码核验。该优化不减少动作样本或更改时间／坐标精度。格式、迁移与回退见 [轨迹无损压缩与存储升级](轨迹无损压缩与存储升级-20261016.md)。
