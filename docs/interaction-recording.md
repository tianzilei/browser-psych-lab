# 操作记录与回放

> 并发、准入和容量口径已于 2026-10-11 同步。完整预算、默认 2／1 与特定 ECS 7／7 的区别见 [并发设计与容量验收](并发设计与容量验收.md)。

参与页和图片任务保存浏览器提供的触摸、鼠标/触笔按下/移动/释放/取消、点击、键盘、输入、焦点和输入法事件。拖动包括浏览器提供的全部合并样本，并保留压力、接触宽高、tilt/twist、修饰键。还包括 beforeinput、compositionupdate、wheel、指针捕获和页面/网络/视口状态变化。copy/cut/paste 只记录操作类型，不读取剪贴板内容。时间使用 `performance.timeOrigin + at`，坐标采用视口内 CSS 像素，键盘事件没有指针坐标。

每次界面变化保存可见元素位置、文字、基础样式、控件值、视口/DPR/滚动信息及图片资源 ID。`rt_ms` 是该题或当前评分项显示后的操作时间；图片任务另有从图片绘制到首次选择、最终提交的反应时间，以及各评分项首次/末次选择时间。旧记录不能补生成未采集的动作。

动作以 `interaction-v1` 批次保存到独立 `d-ui-*` 诊断链；不改变答案链、封存或实验调度。本机 IndexedDB 保存后再补传，服务器原始数据保留。相同界面快照去重，动作不去重；批次限制为 64 条/约 90 KiB，100 ms 刷写。显式页面/刺激快照同步；同 microtask 的普通输入快照请求合并，滚动快照按帧合并并保存 capture 标记。最多 1900 节点且标记截断，单事件仍为 128 KiB预算。本机队列或磁盘写入失败会停止作答并提示恢复，不静默丢弃。较大批次使用可选原生 gzip，原文及 SHA-256 身份保持。详细合同见 [轻量采集与传输](浏览器轻量采集与传输设计.md)。

管理员从“查看答卷与回放”进入回放页，可以播放、暂停、拖动时间轴、逐动作查看。回放使用当时的布局/图片、输入值和触点轨迹重建，JSON 显示每个动作完整字段。CSV 中 `interaction_actions` 包含动作和界面快照，`trial_results` 包含评分反应时间，`reanswer_links` 保存重新作答前后关系。

回放是软件记录的重建，不是屏幕视频：浏览器之外的动作、未派发的物理采样、系统键盘界面、操作系统渲染与物理显示延迟不在记录中，原生控件和字体换行的视觉表现可能与原设备不同。

“重新作答”创建新会话，并对旧本机会话元信息归档。服务器保留旧答卷，通过不可修改的关联表和 `REANSWER` 标记关联新答卷。新会话使用同一问卷最新版本，前提是知情同意文本相同，否则保留原版本。

纯问卷（没有实验任务组）不限制同时作答名额，也不占用任务名额；带图片或定时任务组的版本满额立即 409，手动稍后重试。服务的 HTTP、数据库和资源保护仍生效。
