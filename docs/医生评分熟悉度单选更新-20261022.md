# 医生评分熟悉度补充题改为单选

2026-10-22，北京时间。“医生第一印象评分”的熟悉度补充题更新为：

> 在参加本研究之前，您和照片中这位医生是否认识？

滑块改为六项单选，保留原有分值与标签：

| 分值 | 选项 |
| --- | --- |
| 1 | 从未见过 |
| 2 | 见过 |
| 3 | 多次见过 |
| 4 | 有过接触 |
| 5 | 多次接触 |
| 6 | 非常熟悉 |

界面完整显示各档文字。没有默认选择；未选择时不能进入下一题，每张照片重新选择。顺序仍为照片显示、五项印象评分、熟悉度、年龄估计，照片在补充题期间保持显示。熟悉度继续使用既有数值事件、封存及导出字段。

协议新增可选 `rating.familiarity.control="single"`。未配置时继续使用滑块，已有协议形状及归档运行器保持原样。正式评分和模拟共用单选控件，支持触控及原生单选键盘操作。
