## 数据与软件时序合同

`lab-events-v1` 使用 session/event_id/hash 作为原始接管身份；接收得到 PERSISTED custody 后可从发件箱移除，原始 IndexedDB 事件仍保留。ACCEPTED、RECEIVED_PENDING 和 QUARANTINED 为独立处置版本，不把接管当成语义通过。异内容分别保留原字节与 receipt；有缺项/额外项/隔离项不能正常封存。清单序列化固定为 manifest_id、scope、events 的 event_id/hash、path，避免对象构造顺序影响摘要。

页封存要求修改链最后一项为 PAGE_SNAPSHOT，条件由同一共享解析器验证；隐藏值留在修改历史中，最终投影是 SKIPPED/null。组封存要求服务端维护 worker 重放来自同一读视图的全部 ACCEPTED 事件，并在短写事务中重新核对源摘要、写者、许可、路径和精确集合。参与端不能提交自己的重放证明。

Canvas 运行器保留全局计划时点，不因迟到 callback 平移余下计划。开始前测量刷新间隔、全事件编码/摘要/metadata/events/outbox 的四段串行 strict IDB 路径、实际可用几何及冻结资源。超预算不能开始。发生未提交开始意图、事务完成通知迟到、失去可见性、几何变化、错过图片窗、长帧或保存失败时终止，保留未知/软件观测状态。

响应以归一化输入时间和软件绘制/清屏窗口归属，第一次合法新触下锁定答案；后来的正确答案不覆盖第一次错误答案。释放和持有手指不能作答，多触和窗外输入保留。GROUP_CLOSING 后的输入进入独立诊断 scope，不改变组清单或重开补测。终止会话会继续补传并生成明确不允许清理的对账报告。离线且原本地库/Cookie 丢失时，代码无法恢复不存在的字节。

调度只在 OP 的 strict IDB 事务完成**通知**到达且仍在截止点内后 ack；INSERT/CANCEL/INTENT 前后计划与随机消费全部留存。已提交 intent 不能取消或复用；STAGED 的迟到纠偏终止整个运行，已有软件 onset 的候选保留完整固定阶段。服务端不把浏览器观测解释成物理发光或物理触摸时间。

## 有界策略

HTTP JSON 最大 1 MiB，上传 8 MiB；接收入口最多 32 个、20 MiB 的双份字节计费；DB RPC 队列 32 个/2 MiB，保留控制余量。Lab 批最多 32 项/512 KiB、单项 128 KiB、scope 最多 5,000 项/32 MiB；浏览器串行等待队列最多 64 项。原 P0 的更小预算保持独立。

图片像素最多 4,000,000，静态 PNG/JPEG/WebP，拒绝动画、异常方向和解码警告；保留原始字节，不做在线格式替换。协议验证组解码上限、最坏时长与最坏审计事件大小，开始许可还验证量化后的最坏时长。测试默认解码预算 32 MiB。

最新准入目标为阿里云 1Mbps 下同时 1–2 例，原 2c4g 正在评估降为 1c2g。`SESSION_CONCURRENCY=2` 默认双例，支持 1；持久 FIFO 最多 64 个活动/等待条目。问卷、准备、运行与封存占位，等待页不显示题目；完成/明确终止释放，无 ISSUED 的失联 5 分钟回收，ISSUED 始终占位。刷新保留有效序位，主动退出再加入排队尾；服务端开始路径在短事务中检查准入，拒绝后入队状态仍已提交。规则与小规格模板见 [会话排队与小规格部署](会话排队与小规格部署.md)。

图片准备另设最多 64 个票据，默认放行一个会话、一个流；每组串行下载/解码，排队 45 分钟、准备 20 分钟、图片 60 秒无进展即失败。按 nonce 精确取消，名额随真实流退出回收；组内停止全部准备网络活动。旧冻结 GET 在原 Cookie/版本引用授权后共享 FIFO，保留旧 20 秒客户端超时，服务端排队最多 18 秒。新能力声明纳入运行器摘要，缺票据拒绝；能力冷读取合并且有界。预算与限速报告边界见 [阿里云 1Mbps 部署与验证](阿里云1Mbps部署与验证.md)。

冻结运行器原 JS/CSS 的压缩副本在构建和归档时核对解压身份；编码协商保留 Vary、明确拒绝时 406。相同归档重启跳过多余写入/fsync，新文件 0600；恢复保留 canonical 能力声明、原代码及全部压缩副本。私有图片仍不缓存/压缩/改字节。

维护 worker 同时一个，120 秒监督期限，实际退出后才能替换。重放/导出/重建读视图 30 秒，CSV 100 MiB/200,000 主表行，重建 1,000 组/4 MiB 返回结果，备份资产 512 MiB；超限失败并登记 RECOVERY_REQUIRED，不截断冒充成功。失败文件保留，维护者填写核查报告并核验文件后结束旧作业；删除只针对有显式删除意图且无引用/pin 的资源及其临时文件，不按年龄自动 GC。

## 尚需外部环境验收

代码及本机可执行流程已落实。以下无法由当前工作区替代，仍未标记通过：

- 目标服务器部署、实际 HTTPS、真实 OS/文件系统目录耐久性、磁盘满/断电、RPO/RTO 与升级演练。
- 独立备份目的地及实际完整恢复演练。当前本机备份结果明确 `independent:false`。配置 BACKUP_ROOT 时拒绝与活跃存储相同 filesystem 的目标，复制后重核摘要；物理独立性仍由维护者确认。
- 首批真实手机、浏览器/内置宿主、设备预算与最终选择的阿里云 1c2g/2c4g、1Mbps 主机上最多单例/双例活动和集中到达排队。

正式 gate 开放需要不可变环境档案、READY 的独立备份、与该备份对应的恢复清单摘要及维护者恢复确认；还将 gate 绑定到具体 environment_id。开发夹具不能直接开启。恢复工具始终关闭 gate 并撤销旧管理登录，不推断未关闭 permit 已正常结束。

P5B 物理测量及后续 S3 迁移是设计列出的后续路线，未计入首版软件实施完成。

最终本机验证：52 项单元/故障测试、19 项 Chromium 测试、TypeScript/build/SQLite smoke 全部通过；doctor 结果记录在开发环境文档。此前生产依赖 npm audit 返回 0 项漏洞，本轮未改变依赖；不将历史审计作为持续保证。大 SurveyJS chunk 仍按需加载，构建保留体积提示，未宣称消除该库的内存开销。
