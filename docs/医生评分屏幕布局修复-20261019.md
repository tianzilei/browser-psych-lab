# 医生第一印象评分的屏幕布局修复

2026-10-19，北京时间。修复管理端模拟窗口的照片过高、评分控件不可见，以及正式作答页评分框边界与提交按钮重叠。

## 原因与修改

模拟页没有正式运行器的 `runner-layout` 类，图片所在网格使用百分比高度，却没有明确的可用视口高度。704×755 窗口中，实际页面高达 1425 像素，评分按钮全部位于屏幕外。现在包含 `.runner-stage` 的页面统一受到可见视口高度约束，图片容器使用尺寸隔离并允许缩小，照片完整等比显示在剩余空间内。

正式页将评分区固定为 190 像素，内部固定为 36＋146 像素。生产 HTML 还将公共 participant CSS 放在 runner CSS 之后，同等优先级的 `.axis-control` 覆盖了评分框的内边距、间距和对齐方式，使边框超过预留高度。现在评分区按内容分配高度，评分框使用更明确的选择器，公共样式后加载也不会覆盖其布局。熟悉度和普通评分轴共用规则；短窗口采用紧凑间距，为照片、44 像素高的滑动条、年龄键盘与 48 像素高的提交按钮留出空间。

## 验证

- 运行器浏览器回归 22 项通过；补充按生产顺序加载公共 CSS 的三种尺寸专项测试，3 项通过。
- 使用线上当前问卷定义与图片，在独立本机数据库运行 704×755、900×1280、390×844、320×480、600×650 五种窗口尺寸，检查熟悉度、五项评分和年龄，共 35 个作答阶段。控件均在视口内，评分边框没有侵入按钮区域；选择评分、切题和输入年龄时照片几何尺寸保持不变。
- TypeScript 检查通过。测试答卷保存在独立数据库，没有向生产数据库写入测试答卷。
