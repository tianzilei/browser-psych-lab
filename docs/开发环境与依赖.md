# 开发环境与依赖

准备日期：2026-10-08（Asia/Shanghai）。当前已实现首版 P0–P6 业务代码，正式采集仍需环境验收。最新验证见 [P1–P6 实施记录](P1-P6实施与验收.md)。

## 1. 环境

- Node.js 24.21.0，使用 `.nvmrc`／`.node-version` 固定；本机已通过 nvm 安装。选择 Node 24 LTS，依据[官方发布列表](https://nodejs.org/en/about/previous-releases)。
- npm 11.19.0；所有直接依赖使用精确版本，间接依赖与完整性摘要由 `package-lock.json` 锁定。
- npm 原生构建脚本已按版本列入 `package.json` 的 `allowScripts`：better-sqlite3 13.0.3 和 esbuild 0.28.2。升级对应版本时需同步检查；不执行参考仓库的脚本。
- SQLite 由 `better-sqlite3` 提供；无需数据库服务或 Docker。本机实际引擎为 3.53.4。
- 本机已有 Xcode Command Line Tools；在无对应原生预编译包的平台需要 Python、C/C++ 编译器和平台构建工具。
- Chromium 由 Playwright 单独安装，用于工程浏览器回归；手机与内置浏览器仍需真机验证。

## 2. 初始化与运行

```sh
nvm install
nvm use
npm ci
npm run setup
npm run references:fetch
npx playwright install chromium
npm run doctor
npm run check
npm run dev
```

`setup` 只在 `.env` 不存在时按示例生成，不覆盖已有配置；数据库和私有目录可重复初始化。开发网页为 `http://127.0.0.1:5173`，API 为 `http://127.0.0.1:3000`。Vite 将 API 请求代理到后端。

构建后由 Fastify 提供网页与 API，验证单应用同源部署入口：

```sh
npm run build
NODE_ENV=production npm start
```

访问 `http://127.0.0.1:3000`。这里的 production 仅控制使用构建产物；正式采集仍须完成 HTTPS、认证、业务合同、设备、容量和备份验收。默认绑定回环地址。

## 3. 工程内容

| 位置 | 内容 |
| --- | --- |
| `src/server/` | Fastify、单 DB worker、有界接收/队列、SQLite 接管/封存、运行许可及静态服务 |
| `src/shared/` | 冻结测试合同、身份/状态、PRNG 与补测调度纯逻辑 |
| `src/web/` | 组件检查页及 `/p0.html` 可靠问卷；IndexedDB 事件/outbox/提交意图 |
| `scripts/` | 初始化、依赖／源码检查、开发进程、隔离数据库测试 |
| `scripts/profile-foundation.mjs` | 构建载荷及本机 TEST_ONLY 只读健康检查；不代表参加者容量 |
| `scripts/precompress.mjs` | 构建时预压缩公共 JS/CSS；不压缩私有研究文件 |
| `scripts/release.mjs` | 将原代码及队列能力声明纳入运行器摘要，记录并核对预压缩副本 |
| `scripts/profile-mixed.mjs` | 隔离 HTTP/SQLite/图片/重放/CSV/备份的 1/5/10/20 会话集中到达，整例准入上限 2，设置 SESSION_CONCURRENCY=1 可测单例 |
| `scripts/profile-bandwidth.mjs` | 20 会话先排整例队列、后排单流图片准备，下载后 TEST_ONLY 终止；累计 loopback 响应正文 125000 B/s 限速 |
| `tests/unit/` | 接收/封存、writer、整进程崩溃、PRNG 与调度故障测试 |
| `tests/browser/` | Chromium 中断网/刷新/丢 ACK/单写者/原子回滚及组件/访问/缓存检查 |
| `references/` | 固定源码身份、许可证证据、参考入口、PRNG 源码及黄金输出 |
| `var/database/` | 本地 SQLite 文件，禁止提交 Git |
| `var/research-assets/` | 私有研究资源，已实现按版本/会话授权网关 |
| `var/research-exports/` | 私有导出目录 |
| `var/research-backups/` | 同机开发备份目录，独立备份待配置 |

检查页的 SurveyJS 渲染样例答案不保存，IndexedDB 探针完成后删除。另一个 `/p0.html` 入口保存固定测试问卷，使用持久事件/outbox/提交意图及逐项接收/封存凭证。浏览器回归使用临时数据库和私有目录。源码、依赖、构建产物与本地数据分别保留在相应位置；大型参考 checkout 不提交主仓库，可按锁文件重新获取。

## 4. 锁定依赖

| 分类 | 包／版本 | 用途 |
| --- | --- | --- |
| 服务 | fastify 5.12.5、@fastify/static 10.1.5 | 单应用 HTTP 服务和构建后网页 |
| 数据库 | better-sqlite3 13.0.3 | SQLite 驱动 |
| 普通问卷（构建时安装） | survey-core 3.2.0、survey-js-ui 3.2.0 | 模型与原生 JavaScript 渲染；两个包版本一致；网页按需加载 |
| 浏览器存储（构建时安装） | idb 8.0.4 | IndexedDB 事务封装；进入浏览器产物 |
| 构建 | typescript 6.0.3、vite 8.3.3、tsx 4.23.15 | 类型检查、网页构建、开发运行 |
| 类型 | @types/node 24.19.1、@types/better-sqlite3 9.6.0 | 与 Node 主版本匹配的类型及数据库类型 |
| 浏览器验收 | @playwright/test 1.64.0 | 组件和服务入口回归 |

Canvas、帧回调和 Web Locks 使用浏览器原生能力。jsPsych、lab.js、JATOS 和 Form.io 的源码供参考，不安装为运行依赖；SurveyJS Creator、S3 SDK 和 S3 服务不进入首版依赖。

服务端生产直接依赖只有 Fastify、@fastify/static、better-sqlite3、sharp 四个包。SurveyJS/idb 与构建、类型、浏览器测试工具均在 devDependencies；这只是安装范围分类，SurveyJS/idb 仍在网页产物中运行。先在完整构建环境生成 dist，再在发布目录用相同 package.json／package-lock.json 执行 `npm ci --omit=dev`；不能删掉构建依赖后再构建。发行环境还须按 P1 准备私有目录、配置、TLS 与服务守护，本次没有开放正式采集。

公共 hash JS/CSS 构建时生成 gzip/Brotli，服务直接发送压缩副本并设 immutable；HTML no-cache、API no-store。私有图片／导出／备份不进入 public static。HTTP 默认逐请求日志已关闭，失败日志仅保留请求身份和状态，认证字段脱敏；P0 已持久记录接管、处置及冲突/迟到诊断，研究管理与维护审计已通过 lab_* 历史表实现。

升级要同时更新锁文件、参考源码身份和验证记录。浏览器体积、冷加载与时序结果仍按项目实测；构建日志给出当前产物体积，不能替代目标设备验收。
