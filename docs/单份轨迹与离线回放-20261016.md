# 单份轨迹与离线回放（2026-10-16）

管理页面移除了问卷删除入口，服务端删除接口同时拒绝操作。隐藏、改名、排序、JSON、问卷模拟和答卷结果导出继续可用。

“查看答卷与回放”仅显示具有有效界面快照的会话，并在入口显示数量。当前服务器 50 份答卷中有 15 份可回放，其余 35 份的原始记录和答卷均保留，结果 CSV 仍包含这些会话。派生索引在筛选后分页，避免无轨迹会话挤占列表。

每份可回放答卷提供两个文件：

| 文件 | 内容和用途 |
| --- | --- |
| JSON.gz | 该会话全部保留的 `d-ui-*` 原始 UTF-8、SHA-256、处理状态及接收凭证，适合程序分析 |
| HTML | 同一份压缩证据、交互播放器和所需图片，适合下载后直接离线回放 |

HTML 支持播放、暂停、时间轴和逐动作查看；打开时逐条核验原文哈希及图片哈希。页面禁止网络连接和外部资源，不需要管理 Cookie。播放器使用规范且格式有效的批次，文件仍保留非规范或被拒绝的原始证据。记录按原精度保存，视觉回放属于布局和操作记录重建；原设备字体、系统控件或未采集动作不能由此还原。

采用 HTML 后没有部署 x265 编码任务，也没有视频缓存。文件名采用 `问卷名_会话前8位_YYYY-MM-DD_HH-mm-ss`，时间为本次下载时的北京时间。批量轨迹 CSV 通道仍然关闭。

## 真实数据测量

在生产服务器的数据库快照上，按压缩存储量选择最小和最大的可回放会话。以下为单次生成测量，包含文件生成及原文校验，不代表并发或公网下载承诺。

| 样本 | 原始批次数 | JSON.gz | HTML | HTML 生成时间 |
| --- | ---: | ---: | ---: | ---: |
| 最小 | 28 | 16,925 B | 93,751 B | 111 ms |
| 最大 | 1,060 | 1,526,431 B | 2,043,331 B | 2,070 ms |

最小样本的 HTML 包含一张图片，最大样本没有图片引用。导出在独立只读工作线程中执行，同一服务同时生成一份；完成或断开后立即移除派生文件。每日北京时间 00:00 清理超过一小时的异常残留，仅作用于私有的 `research-recording-downloads/<UUID>` 目录。

在线回放接口也增加了异步 gzip 传输，最多并行压缩两份响应，保留客户端编码协商。最大样本的第一页从 690,504 B 降为 22,803 B，减少 96.7%；解压后的 JSON 字节摘要与更新前相同。

## 验证

本地通过 150 项单元测试和 63 项浏览器测试，覆盖删除禁用、快照资格、筛选分页、重试索引、原文摘要、离线图片、脚本隔离及临时文件清理。生产数据库核查对比发布前后原始表逐字段内容，核验 10,749 条原文及事件摘要；保留 50 个会话、37 个冻结版本、150 份封存记录及全部处理历史。SQLite 完整性和外键检查通过。

生产浏览器验证了全部 11 个问卷的回放入口筛选、删除接口拒绝、未登录下载拒绝、不可回放答卷下载拒绝，以及最小／最大样本的 JSON.gz 和离线 HTML。最大样本在线加载约 5.4 秒；离线文件在新的未登录窗口中通过播放、暂停、前后动作和时间轴检查，没有 HTTP 请求或页面错误。5 份历史答案 CSV 的内容哈希保持一致，批量轨迹 CSV 继续返回 410。

每日清理服务已启用，首次计划运行时间为 2026-10-17 00:00（北京时间）；使用过期的测试临时目录验证清理成功，原始数据未变。测试生成的视频文件已移除，临时管理会话在验收后撤销。
