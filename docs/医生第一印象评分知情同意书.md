# 医生第一印象评分知情同意书

感谢您参加医生第一印象评分研究。请阅读以下说明，自愿决定是否参加。

本次试验预计花费15分钟。试验中您将随机查看 20 张医生照片，请根据第一印象，评价医生的可信程度、专业能力、亲切友善、外貌吸引力，以及选择这位医生为您诊治的意愿，五项评分均为 1–9 分。随后请您评价对照片中这位医生本人的熟悉程度，并评估该医生年龄。

评分没有标准答案，请按您的直观感受作答。每张照片提交后间隔约 3 秒，再显示下一张。

系统会保存上述答案、照片呈现顺序及作答时间等信息，信息仅用于研究分析和运行质量检查。除为发放受试者补偿费而收集的手机号外，不保存其他可以识别受试者身份的信息。

您可以选择不参加，也可以在作答过程中随时停止并关闭页面，退出不会自动删除已经保存的记录。完成全部试验后请等到页面明确显示“研究已完成”再关闭。对于完成全部试验的受试者，我们将在试验结束后7天内为您发放受试者补偿费人民币10元。

如果您理解并愿意参加，请点击“我已阅读并同意”；如果不愿参加，请点击“不同意并退出”。
