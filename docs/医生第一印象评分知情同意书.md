# 医生第一印象评分知情同意书（试运行）

本任务用于试运行医生第一印象评分流程。请阅读以下说明，自愿决定是否参加。

您需要做什么

您将依次查看 32 张医生照片。请根据每张照片给您的第一印象，分别评价可信程度、能力、温暖程度、吸引力、选择其作为自己医生的可能性，以及您对这位医生的熟悉程度。六项评分均为 1–9 分，请按照页面的文字提示选择。

每张照片还需要填写您估计的医生年龄。这是对照片中人物年龄的判断，不是询问您本人的年龄。每张照片提交后间隔约 3 秒，再显示下一张。评分没有标准答案，请按自己的真实感受作答。

任务会记录哪些信息

系统会保存六项评分、您估计的医生年龄、照片呈现顺序及作答时间，并记录浏览器、设备、屏幕、网络连接和服务器接收时的 IP 地址等信息，用于分析评分及检查任务运行情况。

设备记录还包括语言、时区、浏览器权限状态，以及浏览器允许提供的电量、存储和图形设备信息。

本任务开启操作轨迹记录，会保存任务页面内的点击、触控、拖动、按键、输入、题目切换和页面状态，以及当时显示的题目、控件和表单内容。这些记录供研究者分析作答过程及排查问题。本任务不要求您提供姓名或联系方式。

自愿参加与退出

您可以选择不参加，也可以在作答过程中随时停止并关闭页面。退出不会自动删除已经保存的评分和操作记录；未完成的答卷也可能保留已有内容。

如决定参加，请保持网页可见和设备竖屏。结束时请等到页面明确显示“研究已完成”再关闭；若保存尚未确认，请保留原页面，并联系邀请您参加本任务的研究者。如对任务或数据使用有疑问，也请联系该研究者。

如果您理解并愿意参加，请点击“我已阅读并同意”；如果不愿参加，请点击“不同意并退出”。
