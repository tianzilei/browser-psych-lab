## 控件与布局

- 常规控件：最小触控高度 48px、16px 主文字、10px 圆角、8px 同组间距；可操作边框与结构分隔线分开设色。
- 逐题选项按内容自然高度排列，空间不足时测量更多列；完整内容仍不能容纳时阻止继续。个人信息输入组靠近题干，导航保持底部位置。
- 多选方框与勾号使用装饰节点，`aria-pressed` 与完整选项文字保持原语义。
- 逐题与自适应共用选项键盘操作。方向键仅移动按钮组焦点；熟悉度 radio 继续使用原生选择行为。
- 个人信息采用可见 label、`aria-describedby`、`aria-invalid` 与单一活动错误区域。组合输入和软键盘变化期间保留输入节点、焦点与草稿。
- 自定义冻结背景通过一次性颜色计算生成可读边框、辅助文字与错误色；不修改背景字符串或跟随系统主题变化。
- 手机号题在创建控件前声明布局，避免长题干与键盘挂载相互触发重排。
- 长手机号题干先允许完成阅读分页，只有进入输入／提交阶段才按号码有效性关闭主操作。

## 评分紧凑变体

`ratingControls()` 设置 `data-control-variant="rating-compact"`，对应规则集中在 [runner.css](../src/web/runner.css)。

| 项目 | 当前规则 |
| --- | --- |
| 轴交互热区 | 44px；轨道 3px、可见滑块 22px |
| 年龄数字键盘 | 六列两行、键高最小 44px、键距 4px |
| 熟悉度 | 原生 radio，16px 文字，行高最小 44px |
| 高度不超过 600px | 年龄框 44px、题干 16px / 1.4、局部间距 4px |
| 主提交按钮 | 48px，切题与等待期间保持外框 |

隐藏的评分题型、熟悉度与年龄区共同预留空间，运行前按实际 DOM 测量几何。保留协议最小 Canvas 宽度、准备后布局检查和运行中几何变化中断规则。回归验证覆盖 CSS 加载顺序、320×480、分数反馈、年龄错误、拖动跨题及熟悉度切换时的照片位置。

新构建生成新的 `runner_hash`，不修改 `RUNNER_VERSION` 合同常量，不改旧归档、冻结协议、原始事件或导出答案。当前构建身份与相关源码散列记录在验证摘要中。
