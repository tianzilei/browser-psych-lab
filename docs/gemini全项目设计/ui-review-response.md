### 1. 信息层级与文案去重边界

- **参与页标题与说明去重**：
  - **Header**：仅展示全局研究标题（`protocol.title`）。单行省略，保持基线固定。
  - **正文说明块（Intro）**：按 `\s+` 规范化空白后去重。若 `page.title === protocol.title`，正文隐藏 `page.title`；若 `page.instruction === page.title`，仅渲染一次。若三者去重后为空，直接挂载首题，消除首屏无意义空白。
  - **安全边界**：去重仅作用于 DOM 渲染视图，`protocol` 原始 JSON、冻结协议镜像与导出的原始快照完全不修改。
- **进度与错误占位（Grid 塌陷修复）**：
  - Header 统一为紧凑进度：说明段展示 `说明 1/3`，问卷题目展示 `3/12 题`。
  - 移除 `.question-error` 的空白隐式行高。默认 `display: none` 或仅在包含文字时注入行内文本，杜绝无错误时的空白网格抖动。
- **知情同意与结束页**：
  - 拒绝页技术文案收敛：“已退出。未记录任何信息，可直接关闭此页面。”
  - 结束页移除套话叠加：统一主标题“研究已完成”，副文案“数据已保存，感谢参与”，下方仅保留主操作。

### 2. 系统状态与按钮标准化词表（统一收敛）

消除各页面混用与技术代号泄露，采用双层提示：**主要状态（中性明确）+ 次要详情（折叠/小字）**。

| 场景 / 原状态 | 规范展示文案 | 操作按钮（统一用词） | 辅助与诊断说明 |
| --- | --- | --- | --- |
| **容量拒绝 (409)** | 当前参加名额已满 | `返回主页` | 请约 30 分钟后重试（保留 409 无轮询语义） |
| **续活失败 / 失联** | 任务连接已断开 | `重试连接` | 网络未响应或长久未操作；本地记录已留存 |
| **保存中** | 正在保存… | 禁用所有提交按钮 | 进度反馈，避免二次点击 |
| **本地待补传 (Restore)** | 未完成内容待同步 | `同步数据` | 仅保留单一恢复按钮；折叠显示底层状态码 |
| **数据已确认** | 已保存 | `下一题` / `完成` | 收到服务端 ACK 后方可显示“已保存” |
| **任务准备** | 资源准备中 (0%) -> 准备就绪 | `开始本组` / `取消` | 取消按钮文案统一为“取消并返回” |
| **固定刺激运行** | 第 N 次呈现 | 选项按钮（无多余主控） | 不显示误导性“最多 M 次”；保留单一响应选中态 |
| **图片评分多步** | 第 1/2 张 | 步骤 1：`下一题`；步骤 2：`提交评分` | 年龄输入增加明确范围提示：“请输入 0–120” |
| **管理端会话状态** | 状态：活跃 / 已完成 / 已终止 | `查看数据` / `重放` | 中文状态标签后括号附带真实英文状态与 ID |

### 3. 交互逻辑与状态机修复

1. **恢复页（Restore）合并与输入保护**：
  - 移除“重试保存与核对”与“返回当前题目”的双按钮冗余，统一为单个主按钮 `同步数据`。
  - 修复 `restore` 重置活跃输入的问题：给问卷容器增加 `data-input-active` 标记。当输入框处于 `focus` 或处于组合输入（`compositionstart`）期间，禁止外部异步事件重绘 DOM；仅当处于明确的挂起恢复状态（`PENDING_RESTORE`）时，才允许执行全量视图恢复。
2. **固定刺激呈现反馈**：
  - 运行 Header 的状态文本固定为单行高，将“本组已呈现 N 次 · 最多 M 次”调整为“已呈现 N 次”。动态重测补测次数不作为分母预设，避免被试误判终止时机。
  - 按钮在点击后挂载 `aria-pressed="true"`，并保持 `:active`/`:focus` 状态直至试次结束，消除“已记录：Left；请等待下一刺激”等冗余文字对 Canvas 区域的视觉干扰。
3. **滑动评分流与辅助技术修复**：
  - **消除多重重复**：Header 仅保留 `第 1/2 张` 进度；图片下方只保留题干 `h2`；滑块自身 `value` 仅由原生 `<output>` 渲染当前数值或文本标签。
  - **降噪 `aria-live`**：移除滑块在 `input`（实时拖拽）事件中高频更新全局 `aria-live` 的逻辑，仅在 `change`（指针释放松手）时触发单次读屏提示，避免读屏软件音频阻塞。
  - **步进按钮语义修复**：单张图片的评分与年龄附加题属于同组复合任务。第一步必须明确为 `下一题`（未填写滑块时 `disabled`），第二步附加题提交才显示 `提交评分`。年龄输入框标注 `min="0" max="120" placeholder="0–120"`，杜绝非法提交拦截却无说明。

### 4. CSS 细节与时序/布局安全防线

- **固定高度防御（防止 Canvas 抖动）**：
  - 固定刺激页面的 Header、Canvas 容器、Status 行必须采用固定 `height` 或 `min-height`（例如 `status` 区域固定 `min-height: 24px; line-height: 24px;`），并设置 `overflow: hidden; text-overflow: ellipsis; white-space: nowrap;`。
  - 确保即使极端文案注入，也不会引发 Canvas 容器父级尺寸变化或重排（Reflow），保护 RAF 循环期间的渲染几何稳定。
- **色彩统一与视觉降噪**：
  - 列表页统一采用参与页相同的无彩色（Neutral 灰度）基调，移除高饱和度绿色。背景采用统一暗色变量（`--bg: #121212; --surface: #1e1e1e; --text: #e0e0e0;`）。
  - 列表卡片精简内边距与边框，标题字号降为 `1.1rem`，移除“品牌大字”多层级堆叠，形成 `主标题 -> 问卷列表` 两级扁平结构。
- **触控与移动端安全**：
  - 所有按钮、滑块 Thumb 与选择项统一声明 `min-height: 44px; min-width: 44px; touch-action: manipulation;`，消除移动端双击缩放延迟。
  - 选项容器维持全选项同屏，采用 `display: grid; gap: 8px;`，在视口高度不足时只允许单向滚动，严禁破坏整体视口锁定。

### 5. 潜在风险与实施补充

- **去重逻辑风险**：若研究者在自定义设计中有意配置了与标题相同的提示语（如标题为“焦虑量表”，题干说明为“焦虑量表”且下方无其他说明），空白归一化完全相等强行去重会导致正文空白。
  - *补偿方案*：仅当 `page.title === protocol.title` 时隐藏子标题；若 `page.instruction` 去重后导致整页无任何引导文本，必须保留 `page.instruction`。
- **409 与失联区分风险**：客户端在收到 HTTP 409 时必须严格解构响应体中的 `code`。仅当 `code === 'SESSION_CAPACITY_FULL' || code === 'PREPARATION_CAPACITY_FULL'` 时提示“名额已满”，其余 409（如写者冲突、协议版本不匹配）必须准确降级归类为“状态已失效，请重新载入”，不可全部误报为并发已满。
