日期：2026-10-08（Asia/Shanghai）。依据《轻量化架构与并发稳定性决策》第 5 节和主设计第 18 节推进。本次交付是 **TEST_ONLY 最小可靠问卷链、诊断组合同及调度纯逻辑**，不开放正式研究采集。

## 1. 可运行交付

执行 `nvm use`、`npm run dev`，访问 `http://127.0.0.1:5173/p0.html`。生产构建下对应 `http://127.0.0.1:3000/p0.html`。原组件检查页仍为 `/`；SurveyJS 渲染样例不保存答案，可靠保存页使用一个固定原生表单作为 P0 夹具。正式普通问卷仍按 P2 使用 SurveyJS，不由此测试表单替代。

| 模块 | 实现与边界 |
| --- | --- |
| 共享合同 | `src/shared/contract.ts` 固定 TEST_ONLY 协议、事件 envelope、状态、身份格式、数字/时钟域、精确清单与限额。协议正文存入数据库，版本正文不匹配拒绝启动 |
| 本地采集 | `src/web/local-store.ts` 一次编码并计算 SHA-256；原始事件、outbox、提交意图在同一个严格耐久性 IDB 事务中写入；网络重发取保存的字符串，不重编码事件 |
| 接管与处置 | 原始 UTF-8 BLOB、接管身份、不可变处置历史及当前投影在一个 SQLite IMMEDIATE 事务中处理，COMMIT 后返回；相同 ID/hash 查询原凭证及当前版本；异 hash 独立接管并隔离，不覆盖规范事件 |
| 精确封存 | 页清单与诊断组实际事件集合逐项核对；缺失、额外事件、pending、冲突和路径错误均不能通过。封存与完成凭证持久幂等；同操作 ID 异正文拒绝并记录摘要冲突证据 |
| 写入者与许可 | 服务端 epoch 和持久写入者历史；组外 TEST_ONLY 租约协调；任一未关闭 permit 始终阻止第二写者，不按静默或过期释放；显式未知关闭原子终止会话并关闭许可 |
| 历史补传 | 旧 epoch／终止后的合法授权事件仍接管为历史待核对；不能推动当前答案或正常完成。终止对账逐项列已接管、缺失、未知，P0 不授权清理原始副本 |
| 数据库 worker | `src/server/writer.ts` 与 `db-worker.ts`：一个常驻写 worker，HTTP 主线程一次只发送一个 RPC；解析前接收门控及 RPC 队列均限数量/字节；控制请求留容量，并以至多两次控制再一次 bulk 保持公平 |
| 未知提交 | 尚未发送请求返回 NOT_INGESTED；在途超时/退出返回 UNKNOWN。超时停止接收，确认 worker exit 前不启动替代；查询或补传必须保留原逻辑身份。HTTP 应用目前通过进程重启恢复不可用 writer |
| 单应用所有权 | worker 在写事务中登记本机 PID/随机 owner；另一活跃进程拒绝业务启动。整进程崩溃后只有确认旧 PID 不存在才取得旧库；PID 复用导致保守拒绝，不猜测允许双写 |
| 浏览器运行权 | Web Locks 持续保护本地问卷写入；第二标签页只读。凭据由 HttpOnly、SameSite Cookie 传递，写请求检查 Origin；数据库事务再次核对授权。PUBLIC_ORIGIN 可固定同源和 HTTPS Cookie 策略 |
| 调度纯逻辑 | `src/shared/scheduler.ts`：预建根/候选、K=0/1/2、保护前缀、安全后缀位置、三实例软间隔、持久通知截止点、开始意图、迟到纠偏和不可逆终止；保留操作前后完整队列/目标及抽样审计 |
| 随机源 | `src/shared/prng.ts` 对齐锁定 C 参考的两组黄金向量；小端种子、无符号运算、无偏拒绝抽样、M=1 零消费和有限 draw_budget |

本地接管后仅删除 outbox 项，**仍保留原始事件**；P0 即使封存完成也不自动删原始数据。刷新、断网、服务器已提交但未收到 ACK 都恢复原提交身份；不重新产生答案事件。

## 2. 接口与数据库

所有接口位于 `/api/p0/`，协议入口标明 TEST_ONLY。新会话接入使用固定 request_id 和浏览器安全随机凭据；重试会恢复同一会话/Cookie。会话接口通过相应 Cookie 授权，提供查询、claim/release、permit、ingest/receipts、seal、finalize、terminate/reconcile。暂停入口仅为内部测试命令，没有公开管理路由。batch_id 仅标识传输批次，原始接收身份始终是 session/event_id/hash。

SQLite 使用 `p0_` 前缀 STRICT 表；不删除已有表。raw、封存和处置历史由触发器禁止覆盖或删除，终态和关闭许可禁止回退。方案分配、正式协议发布、资源引用及维护任务尚不在此 schema 内。

诊断组只核对服务端给定的单实例 `TRIAL_INTENT → SOFTWARE_ONSET → WINDOW_CLOSED → TRIAL_ENDED` 证据链，检查 epoch、permit、实例、局部顺序、前序身份/摘要和相同单调时钟域。它允许测试乱序接收及许可封存，**没有呈现图片，也不验证物理或完整实验时序**。动态组的输入归属、窗口水位、调度链与资源重放须在 P4 按冻结协议接入；P0 接口不允许任意研究协议或动态组正常封存。

## 3. 本次验证

本机 macOS arm64、Node 24.21.0、SQLite 3.53.4。`npm run check` 包含类型、生产构建/预压缩、隔离 SQLite 基础夹具、21 项单元/故障测试和 11 项 Chromium 测试，全部通过。浏览器服务改用临时数据库及临时私有目录，自动清理，不写开发数据库。

| 故障/约束 | 验证 |
| --- | --- |
| 精确字节与接管 | 非规范空白原样存入 BLOB；重复接管身份一致；异内容另存；错摘要/越权整批零接管 |
| 事务与封存 | 注入提交前故障完整回滚；清单漏项/额外项不通过；封存/完成原身份查询；终态不能回退；封存后迟到诊断不改变历史完成凭证 |
| 乱序 | 缺前序获得 pending custody；补齐后处置版本升级，原 receipt_id 不变 |
| 接入与写者 | 暂停新接入保留原接入资格；旧 epoch 原始字节保留；租约过期仍不能越过未关闭 permit |
| worker/进程故障 | 有界数量/字节拒绝；在途 UNKNOWN 与未发送 NOT_INGESTED；提交后 native 停顿、worker 退出后查询原身份；整进程 SIGKILL 后恢复凭证，旧 permit 不重开 |
| 调度 | K=0/1/2 到上限；动态短/零 ISI 拒绝；尾部无安全边界终止；实际队列只在通知提交成功后切换；软间隔；取消/新提议身份；STAGED 两侧纠偏；未决开始意图崩溃为 UNKNOWN |
| 浏览器 | 断网持久保存、联网/刷新恢复、接管/封存/完成 ACK 丢失、第二标签页只读、IDB 中止三表原子回滚、跨源写入拒绝；可靠问卷不请求 SurveyJS chunk |

测试故障钩子只存在于夹具或构造注入点，没有生产 HTTP 故障开关。调度的 commit/activate/ISI 数值是测试参数；接收队列、30 秒问卷租约、1 秒事务及 10 秒 RPC 上限也是开发策略，不是目标设备或正式主机验收结果。事务预算超过时回滚并拒绝，不承诺同步 native 调用可被中途抢占。

## 4. P0 当时的剩余工作（后续进度见全阶段报告）

P1 继续实施正式 HTTPS/研究者认证、维护作业、私有资源受控发布/删除、持久屏障/pin 及独立联合备份恢复。P2 接入有限题型、分支状态/最终页面快照、编辑与冻结版本、研究质量查询和单视图导出。P3/P4 接入真实资源门控、方案分配一次、Canvas/input 和上述调度模型的本地持久审计与服务端动态重放。

当前浏览器样例只处理单页诊断问卷。跨浏览器丢失本地数据库、会话 Cookie 或换页写者导致历史 pending 时，需要保留证据并由后续恢复/维护流程处理，不自动改写旧事件或重新作答。移动端/内置浏览器、20 人混合容量、磁盘满/断电、真实 filesystem 与独立联合恢复仍待验收。
