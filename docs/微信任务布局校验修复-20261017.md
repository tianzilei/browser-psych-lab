# 微信任务布局校验修复

2026-10-17。医生第一印象评分在微信内点击开始后返回 HTTP 400 / INVALID_GEOMETRY。服务端修复上线后，用户用原链接在同一台手机重新准备，确认已能进入评分。

## 定位与修复

设备记录显示 Android 微信、约 400×779 CSS 像素视口、DPR 约 2.7，本地保存检查已经通过。错误发生在运行许可的布局校验，原错误详情为 null，没有保留此次失败请求的原始 geometry。

原校验对滑条高度严格执行 `height >= 44`，把 `43.999996185302734` 这样的浮点测量值判为不足 44 像素。该边界在修改前的服务端测试中复现 INVALID_GEOMETRY；手机视口仿真注入相同的微小测量误差后，修复版能够开始评分并完成保存。

服务器比较增加 0.01 CSS 像素的数值容差，用于控件最小高度、画布最小宽度和接近零的坐标。保存的原始 geometry 保持原值。明显过矮、越界、错误选择映射及画布比例错误继续拒绝。

INVALID_GEOMETRY 现在返回具体 reason、actual 和 expected，区分 VIEWPORT、CANVAS_BOUNDS、CANVAS_MIN_WIDTH、CANVAS_ASPECT、BUTTON_COUNT、BUTTON_CHOICE、BUTTON_BOUNDS 与 BUTTON_MIN_HEIGHT。若其他设备仍失败，可以从详情判断具体尺寸条件。

## 验证

类型检查通过。11 项实验服务测试、12 项评分及准入测试、3 项浏览器回归通过。浏览器回归包括 400×779、DPR 2.7 的 Android 微信参数仿真、微小高度误差、评分及年龄填写、正常封存，以及完整 3 秒图片间隔。43 与 43.9 像素的过矮控件、越界控件、过小画布、错误画布比例和选择映射仍被拒绝，拒绝前不会分配运行许可。

用户在修复上线后确认“已能进入评分”。这项实机确认覆盖进入评分，没有将其写成已完成全部照片。
