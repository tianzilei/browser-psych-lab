## 新版作答顺序

显示照片 → 可信程度 → 专业能力 → 亲切友善 → 外貌吸引力 → 就诊选择意愿 → 熟悉度补充题 → 年龄估计 → 提交 → 清屏约 3 秒。

熟悉度题为“补充问题：在参加本研究之前，您对照片中的这位医生有多熟悉？”，仍使用原来的六级标签。照片在五项评分、熟悉度及年龄阶段持续显示。所有问题均须主动作答；滑块的初始位置不算已回答。

新协议使用 `rating.familiarity.position="before-age"`。未配置位置的历史协议仍按原先的照片前熟悉度规则读取，历史协议、记录和运行器档案没有改写。熟悉度独立保存，`ratings` 数组仍为五项印象加年龄，避免改变历史数据的年龄索引。

正式与模拟页面共同使用 `src/web/rating-questions.ts` 管理题目顺序、六级／九级滑动条、年龄键盘、必答校验及前进按钮。模拟采用相同的逐题流程和照片间隔，不写入参加者答卷。

## 简化导出

管理端点击“导出问卷结果”后，含照片评分的研究会自动下载“照片评分 CSV”，下方同时提供普通问卷结果表、照片评分表和设备准备记录的下载链接。

新增 `ratings.csv`，每张入选照片一行，包含：

- 会话、版本、照片编号、类别及呈现顺序；
- 已封存手机号页中的补偿手机号；
- 五项印象评分及各自标签；
- 独立的熟悉度分数、标签及年龄估计；
- 会话状态、许可状态、回答状态、重放错误及时间字段。

完整正常封存的记录标为 `ANSWERED`；中断组中的已提交值标为 `UNCONFIRMED`；未呈现、未提交和重放错误分别标记。导出不会将中断答卷改记为完整答卷。不同历史版本使用其原有题数及标签，具体定义保存在导出说明中。

空表模板：[医生照片评分模板.csv](../examples/exports/医生照片评分模板.csv)。当前新版为 34 列；模板不包含测试或真实受试者记录。
