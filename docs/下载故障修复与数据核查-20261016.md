## 故障与修复

失败导出作业 `9d47c6d7-f974-46f7-b1c5-79bd323061d8` 超过原先写死的 100 MiB 导出总量上限，进入 `RECOVERY_REQUIRED`，从而占据全局维护作业名额，后续导出返回 503。

已通过恢复 API 提交核查报告，核验并保留三个未完成 CSV 的文件清单和摘要，将旧作业转为 FAILED。导出容量现为三个 CSV 合计最多 1 GiB、200 万行、物化写入 90 秒；超限明确失败，不截断后声称成功。普通导出失败时先确认 worker 退出，再转为 FAILED，允许重试和后续导出；涉及资源变更或服务整体中断的恢复要求保留。

## 答案导出优化

“导出问卷结果”现在使用 `format: answers`，仅生成 `answers.csv` 和清单。它从同一数据库读视图读取冻结问卷、会话状态及已封存页面快照，不扫描操作轨迹，不生成完整原始证据文件。CSV 字段、每题／每轴一行的格式、未确认与未到达状态均保留。

“下载数据”和“导出轨迹”保留全量导出。管理页只显示本次实际生成的文件链接，未生成的文件返回 404；旧全量导出和请求结果丢失后的恢复下载仍可使用。

## 关闭轨迹后的单份大小

对最新版本中 14 份已完成、`record_interactions: false` 的同步课题答卷测量，每个部分约 190–191 题：

- 保存的最终答案 JSON 为 6,667–6,702 字节，约 6.7 KB。
- 带题目文本、题号、标签、版本和会话信息的答案 CSV，每份约 69–70 KB。三部分合计约 210 KB。
- 包括逐题修改、自动保存等原始事件正文，每个部分约 160–196 KB；这个数字不包括数据库中的重复投影、索引或页分配开销。

关闭轨迹不删除既有历史轨迹，因此全量证据导出仍可能较大。答案模式不受这些历史轨迹体积影响。
