# 前端页面布局与文字规范

问卷、等待、恢复、退出等待和结束页共用文档流布局。根节点不使用固定坐标；内容由文本和控件自然撑开，超过视口时允许纵向滚动。

## 设计令牌

| 用途 | 规则 |
| --- | --- |
| 正文 | 16px，行高 1.45 |
| 页面标题 | 20px，行高 1.35，字重 600 |
| 题干 | 17px，行高 1.45，字重 600 |
| 状态/进度 | 13px，行高 1.2，字重 500 |
| 说明文字 | 14px，行高 1.5 |
| 感谢页正文 | 15px，行高 1.6 |
| 选项、输入、按钮 | 不小于 16px |
| 触控区 | 不小于 48px 高度 |
| 页面内边距 | 16px 起，宽屏使用 3vw；底部叠加 `env(safe-area-inset-bottom)` |
| 内容宽度 | 题目和结束页最大 900px，状态页操作区最大 520px |

文字只使用字号、行高和字重表达层级。长标题和按钮允许换行，不能通过裁切隐藏关键信息。

## 页面骨架

页面容器使用 `min-height: 100dvh`、安全区内边距和居中的最大宽度。标题、状态、正文和操作区按垂直顺序排列。等待页、退出等待页和恢复页的操作区使用 `flex-wrap`，宽屏横向排列，窄屏自动单列；按钮不能通过 `top`、`left` 或屏幕绝对坐标定位。

问卷页分成题目元信息、题干/答案区和底部导航。外层保持文档流，内部可以使用 Grid。导航按钮使用等宽网格和安全区底部内边距，按钮高度可随文案增长。页面不使用百分比行高填充视口，避免 iPhone 地址栏变化时产生跳动或裁切。

答案区需要同屏呈现全部选项或坐标轴，因此问卷内部保留有限高度，依据可见视口和挂载位置计算。空间不足时阻止提交并提示调整设备；外层仍可纵向滚动以访问导航。文字题题干区至少预留 4.5rem，防止刷新恢复时空节点高度为零而无法分页。

图片计时任务使用独立的 `runner-layout` 状态，限制滚动、按可见视口像素设置容器高度，并为状态文字预留空间。状态文字和开始按钮渲染完成后测量几何；运行期间仍严格检查视口和几何变化。错误、中断或封存重试页面移除该状态并恢复文档滚动。

## 单坐标轴题

单轴题使用独立的 `single-axis-question` 区域。题干区预留约 6rem 的最小高度并底部对齐，题干从一行变成多行时不下压量表。量表轨道位于独立交互区中线，`axis-control` 使用 rem 内边距（当前为 `1.5rem .75rem`），不使用 `dvh` 内边距。刻度和滑块触控热区保持至少 44px，整体按钮和导航保持 48px。

## 结束页

结束页包含标题、可滚动正文和操作区。标题约 22px；正文 15px/1.6；操作区允许分页按钮、重新模拟和“回到主页”按钮换行。操作区保留底部安全区，不写死 44px 高度。点击“回到主页”返回 `/`。

## 验收规则

- 等待、退出等待、恢复和结束状态始终有可见的下一步操作。
- 恢复错误至少提供“重试保存与核对”和“返回当前题目”，后者恢复同一会话及本地答案，不重新进入问卷入口。
- 图片运行结束后恢复普通文档流和滚动。
- 不能用固定高度制造第二屏空白；列表末尾只保留实际内边距。
- iPhone Chrome 窄屏下无横向滚动，按钮文字完整可见，输入框字号不低于 16px 以避免自动缩放。
