## 已修复的问题

| 问题 | 触发条件与影响 | 修复 |
| --- | --- | --- |
| 触摸滚动被全局禁止 | 问卷、恢复或结束页在触摸设备上需要纵向阅读时，document touchmove 被 preventDefault | 仅 runner-layout 实验布局拦截；普通文档页面可滚动 |
| 图片实验准备几何失效 | 准备测量之后改变状态文字、挂载开始按钮，文档流重新排版；两个 runner 测试均报“准备后布局已变化” | 实验布局约束可见视口高度、预留状态文字区域，最终控件渲染后测量；错误和中断移除实验布局 |
| 同屏答案检查失效 | 问卷仅用 min-height，答案区域可无限长高，20 个选项在视口外也能通过区域内部检查 | 按视口与挂载偏移设置有限内部高度，保留外层滚动；不满足预算时阻止提交 |
| 刷新文字题无法恢复 | 空题干节点在 auto 行中测得零高度，分页器无法填入文字，输入控件不渲染 | 题干预留至少 4.5rem；刷新/IME 浏览器回归通过 |
| 长结束语失去分页边界 | 文档流中的正文无限增长，分页器可能认为全文均放得下 | 有限阅读高度，保留分页、正文滚动与独立标题 |
| 长标题裁切、选中颜色错误 | 窄屏标题省略；自定义背景仍使用灰/深固定选中文字 | 标题折行，选中文字使用实际背景 CSS 变量，补充默认主题变量 |
| 伪造 Web Locks | 非安全上下文缺少原生锁时，每个标签都拿到空锁对象，破坏单写者前提 | 删除假锁；入口明确提示支持 Web Locks 的浏览器和 HTTPS；无锁不创建会话 |
| SHA-256 切片范围错误 | BufferSource 为偏移 TypedArray/DataView 时，原实现哈希整个底层 buffer | 复制指定切片；拒绝非 SHA-256 算法；覆盖空输入、块边界与偏移视图 |
| 跨平台测试失败与无效断言 | Windows python3/cat 不可用、POSIX mode 语义不适用；重复结束语相邻分页可能相同 | 使用系统 Python/可配置 PYTHON 与 fs；POSIX mode 仅在对应平台断言；分页文本带序号；标题单独断言 |

## Gemini 意见的处理

Gemini 返回的是审计线索，不是执行验证。早期回复有多项误报，在后续交互中提供调用上下文并纠正，未按其建议放松业务契约：

- IndexedDB 同事务可以读取自身刚写的数据；不加入重复 manifest 项。
- 服务端支持乱序接管并最终核对链；不因 outbox UUID 顺序改变接管规则。
- P0 使用固定协议/路径，不能套用 lab 的动态路径。
- Node 24 的全局 crypto、当前 Fastify LogController 已通过实际运行；不依照旧版本假设改写。
- 有限重试总预算、队列容量、恢复清点上限与 SQLite 最低版本是明确约束，不能视为缺陷后移除。
- 协议冻结后题目轴定义不动态增减；原生 range 已承担拖动，未添加无依据的替代实现。
- theme 变量在应用主题时注入；TextPager 已做字素分页并要求回退边界大于 start，未采纳“无限分页循环”推断。
- 位图 close 已释放底层资源；未把另一个 Map 持有已关闭对象误判为 GPU 泄漏。
- 诊断事件使用独立 d- 作用域；未过滤正式链事件来绕过完整性检查。

部分桥接回复超时、断连或请求归属不确定，已按请求与结果 ID 补取、补审，详见 coverage 的 attribution_notes。第 24 批进度文字不作为审计结论；第 25 批要求联合补审。第 40 批在最终复审中明确补审，第 53 批另行成功发送。最终复审未提出新增确定缺陷；这不构成无缺陷保证。
