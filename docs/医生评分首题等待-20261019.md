# 医生评分首题等待

手机号提交并完成任务准备后，点击“开始本组”，等待 3 秒再显示第一张照片和第一题。模拟问卷在手机号提交、图片解码完成后采用相同的 3 秒等待。等待期间显示“即将开始第一题，请等待 3 秒…”，评分控件不可操作。

等待只在已经填写有效手机号、开始第一组评分时执行。后续照片继续使用原有间隔，纯手机号问卷和没有手机号的评分任务不增加等待。正式任务在等待结束后才申请运行许可、启动评分，因此照片出现时间和评分反应时不包含这 3 秒。开始按钮立即禁用，关闭页面或重开模拟会取消未结束的等待。

浏览器回归覆盖普通和自适应问卷：第 2999 毫秒仍未申请正式任务许可、评分控件仍隐藏，第 3000 毫秒放行；模拟重新开始后，旧等待不会显示照片。知情同意书、问卷内容及历史冻结版本保持原样。
