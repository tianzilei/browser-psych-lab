拟方案：
- 100dvh固定视口+safe area，html/body/main都不滚动，不靠overflow hidden剪掉必需内容；百分比网格分配顶栏、阅读、按钮区、固定底部导航。只显示一题/一个说明屏。
- 长说明/长题干使用纯文本的“上一段/下一段”分页。尺寸/屏幕旋转时仅在问卷阶段重新计算；用实际DOM宽高测量并二分定位适合当前区域的文本，保留全部字符（UTF-16边界需要避免截开代理对）。不在每次输入或RAF重新排版。
- 一题一屏，single/scale点选但不自动推进，multi按压选择/取消，显式下一题。上一题保留答案，分支改变更新后续导航，末题仍“提交本页”。所有提交仅在必答可见题齐全时，异步保存防重复提交。

- 为text题添加可选 input_purpose:'personal'共享字段。旧schema解析向后兼容；新发布版本只有明确标记personal的text题可进入。现有无用途标记的冻结text题处理已问用户（默认推荐停止该题并要求重新发布，避免伪装非个人文字题为个人信息）。编辑器text标作“个人信息输入”，其他题靠按钮。
