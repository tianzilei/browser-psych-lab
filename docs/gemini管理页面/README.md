# 管理页面更新与 Gemini 讨论

日期：2026-10-11。

管理页面增加列表改名、上移／下移、公开／隐藏、独立问卷结果 CSV 和轨迹 CSV。文件修改、下载 JSON 和模拟问卷放入“问卷文件与模拟”，答卷列表支持每批 100 份继续加载，删除采用卡片内确认并保留历史数据。

## 使用方式

- **修改名称**：修改管理页及公开列表的展示名。作答页面仍使用发布时的协议标题；需要修改作答标题或内容时，在“问卷文件与模拟”中替换 JSON 生成新版本。卡片会显示与列表名称不同的原作答标题。
- **上移／下移**：即时保存顺序，管理页与公开列表采用同一顺序。隐藏再公开、重新发布或刷新页面都保留位置。新上传问卷追加到末尾。
- **隐藏／公开**：隐藏后不再接收新答卷，已经建立的会话可以继续。没有发布版本时，公开按钮不可用。
- **导出问卷结果**：下载 `answers.csv`，普通题每题一行，多坐标题每轴一行。包含答卷、版本、题目、状态、数值／文本答案、原值 JSON 和刻度标签。
- **导出轨迹**：下载 `trajectories.csv`，每个界面操作样本或图片任务 `GROUP_RECORD` 一行，保留事件身份、接收状态、源时钟、坐标、按键和完整载荷 JSON。
- **下载数据**：保留原有 `data.csv`，包含协议版本、答卷、原始事件、图片任务试次结果、协变量、知情同意等完整研究证据。
- **查看答卷与回放**：独立显示答卷列表，导出链接不会因查看答卷而被清除。

一次导出生成以上三份 CSV 和 `manifest.json`，来自同一个 SQLite 读取快照。链接允许重下该快照；再次点击导出按钮生成新快照。请求回复丢失时，刷新仍复用已经完成的作业，避免重复导出。下载继续要求管理员登录。

## 数据含义与兼容

名称修改只更新索引展示名和修订号，源 JSON、草稿协议及冻结版本不变。名称以修订号检测并发；冲突时保留输入，可刷新问卷信息后重新保存。排序校验完整的旧顺序和新顺序，在单写入事务内更新；过时列表、重复或遗漏 ID 均拒绝。

新增 `lab_study_order` 表，不改变旧 `lab_studies` 列和既有 INSERT 合同。首次启动按原管理列表的 `rowid DESC` 初始化；后续启动保留已有顺序。管理列表移除原 100 份上限，防止保存局部列表覆盖完整顺序。

结果只将封存页快照确认为答案；`UNCONFIRMED` 和 `NOT_REACHED` 保持空值，分支隐藏为 `SKIPPED`，可选未填为 `UNANSWERED`。未提交草稿的原始修改记录可从完整数据与轨迹查看。多轴零值和负数保留为数字。

扁平 CSV 使用 UTF-8 BOM，文本中可能被表格软件解释为公式的内容加前置单引号；`answer_json`／`payload_json` 保留原始值。所有文件均有各自的字节数、行数、列名及 SHA-256。原 `data.csv` 的 `table,data_json` 合同与精确 UTF-8 原始证据保持不变。

轨迹包含历史、隔离与诊断事件，分析时应使用 `disposition` 和 `reason`。界面动作使用 `time_origin` 与 `at`；图片任务可能只有运行相对时间，保留 `clock_epoch`／`clock_origin`，没有的时间字段留空。文件顺序不是跨时钟的全局时间线。
