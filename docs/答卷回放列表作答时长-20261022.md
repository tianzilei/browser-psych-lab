# 答卷与回放列表增加作答时长

2026-10-22，北京时间。管理页“查看答卷与回放”列表在“* 条记录 · * 个界面快照”后追加“* 秒作答时长”，最多显示一位小数。

`session.list` 新增 `answering_seconds`，使用已有 `lab_replay_index.last_at - first_at` 除以 1000。首末时间按各操作批次的 `time_origin + at` 统计，与回放时间轴一致，支持跨页面时钟。没有操作记录时返回 null，单条记录的时间跨度为零；未完成答卷按已记录范围显示。延迟补传、重复上传和管理页闲置时间不会自行增加时长。

查询只增加已有索引列的算术计算，不扫描或解码原始轨迹，不修改表结构或已有记录。鼠标悬停在列表统计行可查看计算口径。
