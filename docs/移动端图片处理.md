# 移动端图片处理

本地工具先缩放、裁切、压缩，再生成服务器可直接接收的 ZIP。服务器和计时运行器仍使用冻结文件的字节、尺寸与 SHA-256；同一研究版本不会因手机 DPR、网络变化而改变刺激。

```powershell
npm run images:prepare -- examples/images/mobile-plan.json .local/mobile-images-v1
```

输出目录必须不存在。生成 `images/`、`mobile-optimized.zip` 和 `report.json`。写入临时目录，全部写完再 rename 为目标目录；正常写入失败清理临时目录，可重试。所有派生图都读取同一个源文件，不从其他缩略图继续编码；源文件不修改。工具使用已有开发依赖 sharp/tsx，在安装完整开发依赖的本地电脑运行，生产服务器不新增转码依赖。

示例保留图形卡完整内容，生成 2x 和 1.5x 无损 WebP。问卷使用其中一份固定资产：

```json
{"image":{"package":"mobile-optimized.zip","path":"images/mobile-card.webp"}}
```

在最小目标屏幕验收文字、主体及刺激比例后，再上传 ZIP 并发布新版本。

## 配置

源路径相对于 JSON 的目录。variant 覆盖 defaults；未知字段、显式 null、错误类型、Windows 设备保留名和不区分大小写的输出路径冲突报错。所有配置在读取源图前校验。重复源路径解析为同一文件后分组，每组只读取一次源 Buffer，不缓存整个图库。

```json
{
  "schema": "mobile-images-v1",
  "package": "photos-v1.zip",
  "defaults": {"format":"webp","content":"photo","quality":88,"minQuality":78},
  "images": [{
    "source":"masters/person.jpg",
    "variants":[{
      "name":"portrait-card",
      "scene":"feed",
      "viewport":{"width":360,"height":480},
      "density":1.5,
      "fit":"cover",
      "protectedRegion":{"x":0.3,"y":0.1,"width":0.4,"height":0.65}
    },{"name":"detail","scene":"fullscreen","fit":"contain"}]
  }]
}
```

| 参数 | 含义 |
| --- | --- |
| scene | stimulus/avatar/thumbnail/feed/detail/fullscreen/chat/document/banner；默认 stimulus |
| viewport | 逻辑显示宽高（CSS px/dp/pt），不是输出像素；默认场景值 |
| deviceDpr | 目标设备 DPR，默认 2；离线生成固定档位 |
| density | 1、1.5、2、3；默认场景值。3 需要 zoom=true |
| saveData | true 使用最高 1x，仅用于生成明确选定的派生资产 |
| fit | contain 保留所有内容，不把留白编码进文件；cover 按目标比例裁切 |
| focus | 归一化焦点 `{x,y}`，不代表已检测到完整主体 |
| protectedRegion | `{x,y,width,height}`，多个主体的联合框；坐标相对于 EXIF 归一化源图，取值 0–1 |
| content | photo/text；document 默认 text。text 使用无损 WebP/PNG，禁止裁切 |
| format | webp/jpeg/png；默认 webp。透明图禁止 JPEG，文字图禁止 JPEG |
| quality/minQuality | 照片起始质量/下限，默认 88/78；不同编码器不可等价比较 |
| budgetBytes | 文件软预算，超出不继续缩图或突破质量下限 |
| maxPixels | 输出面积上限，默认 4,000,000，不可高于服务器限制 |
| tiles/tileHeight | 按整幅宽度切长图，默认单片输出高度不超过 1024 px |

## 尺寸与裁切

密度为 `min(deviceDpr, density, 2)`；zoom=true 上限 3，省流上限 1。宽度向上取到 32px 桶，按比例推导高度，避免分别取整改变比例。随后限制边长 4096、面积 400 万像素；实际输出不超过裁切区域源像素，禁止上采样。

| 场景 | 默认逻辑框 | 密度 | 适配 | 每图软预算 |
| --- | --- | --- | --- | --- |
| 刺激图 | 360×240 | 2x | contain | 120 KiB |
| 头像 | 64×64 | 2x | cover | 8 KiB |
| 列表缩略图 | 120×90 | 1.5x | cover | 15 KiB |
| Feed | 360×480 | 1.5x | contain | 90 KiB |
| 详情 | 390×390 | 2x | contain | 150 KiB |
| 全屏预览 | 390×844 | 2x | contain | 300 KiB |
| 聊天 | 160×200 | 1.5x | contain | 35 KiB |
| 文档预览 | 960×1280 | 2x | 无损 contain | 300 KiB |
| 横幅 | 360×120 | 2x | cover | 50 KiB |

参数是待实测起点，不保证视觉无损/OCR 正确。文档预览不能替代生产 OCR 输入规范。

1:1、4:3、3:4、16:9、9:16、3:2、2:3 使用同一公式，设置 viewport 即可。contain 不裁切；cover 找目标比例最大矩形，再定位焦点。保护区域扩展 15% 边距，裁切框必须完整包含它，否则降级 contain。未提供保护区域/焦点时居中裁切，保留面积不足 55% 则降级 contain。因此横图切竖图不会默认丢掉大部分内容。

工具没有人脸/OCR/显著性模型，不把居中当成主体检测；研究者可手工提供联合区域。头像还应检查圆形显示掩膜。显示 contain 时可用 CSS/Canvas 纯色留白，禁止非等比拉伸；编码器只按计算好的等比例尺寸缩放，误差限于整数像素取整。

## 长图与预算

tiles=true 生成 `name-tile-001.webp` 等独立文件。先一次整体缩放成 raw 位图，再按输出坐标切片，保证缩放相位和总高度一致；不在每片上重复缩放。report 的 outputRegion 是准确输出坐标；crop 是映射回源图的整数近似区间，完整覆盖源行。源宽不足不放大，每片满足像素限制。中间整体位图限制 1600 万像素（最多约 64 MB RGBA），超出报错，需降低目标宽度。现有计时运行器显示一张刺激，不提供滚动拼图；切片可用于离线检查或另建查看器，不自动成为同一试次。contain 可生成完整长图预览，但小字可能不可读。

EXIF 方向归一化，显式 ICC 转换至 sRGB 后输出，删除 EXIF/ICC 等元数据；广色域/HDR 不在保真范围。几何变换只执行一次，缩放后的 raw 位图复用于质量重试，不通过 JPEG 中间文件。text 使用无损 WebP，PNG 不量化。有损 WebP 不支持 4:4:4 参数。照片从 q88 开始，预算超出时尝试中间值和 q78，最多三次编码，Alpha 保持无损。输出通过项目容器校验；ZIP 存储原始编码字节并提供 CRC，核对后缀/格式，满足最多 100 图、8 MiB 包限制。

报告包含源/输出哈希、像素、裁切框、回退原因、字节、预算超限、质量和 `decodedBytes=width×height×4`。这是一份 RGBA 位图估算，不是整个进程内存峰值。预算超限只报告；质量下限不是感知分。应在真机检验文件大小、文字/OCR、皮肤与渐变、下载/解码时间及缩放体验。

“无损”指缩放后位图的编码无损；缩放本身会丢失原图空间细节，不等于原图像素无损。

报告额外包含 encodeAttempts（编码次数）、rasterBytes（复用的缩放 raw Buffer 大小）、outputRegion（切片目标坐标）和 sourceReads（实际源文件读取次数）。这些是处理计数/Buffer 大小，不是速度或进程峰值测量。

发布用 `目标目录.lock` 避免同一工具并发发布。强制杀进程/掉电可残留该锁和同目录 `.目标名.tmp-*`，目标目录不会暴露部分文件。确认没有运行中的工具后可人工清理这些临时项，或使用新的输出目录；工具不自动删除未知目录。不保证目录发布后的掉电持久性，也不对其他进程主动修改同一输出路径提供通用防护。

Gemini bridge 两轮初审与补丁复审、采用/纠偏记录见 [审查记录](gemini图片审查/README.md)。

源支持当前 sharp 构建实际可解码的静态 PNG/JPEG/WebP/HEIF/AVIF/TIFF，HEIC 依赖本机 libvips 能力；拒绝动画/多页图，源限制 32 MiB、6400 万像素。输出只用平台支持的 PNG/JPEG/WebP。无参考质量模型、自动人脸/OCR、移动端能耗实测、线上 AVIF/HEIC 协商不包含在本工具中。
