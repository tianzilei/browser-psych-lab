# Browser Psych Lab

自托管的浏览器心理实验问卷平台，面向移动端普通问卷与固定图片选择任务，支持预加载、软件时序记录、可靠采集和有界动态补测。

当前状态：v2.0 设计基线已收敛，P0 实施待开始；正式采集准入待验收。

## 技术基线

TypeScript 单仓库、Node.js/Fastify 单应用、PostgreSQL、文件系统实现三个逻辑存储区。普通问卷采用 SurveyJS Library；图片任务采用 Canvas 与浏览器帧调度；浏览器端使用 IndexedDB 本地事件及发件箱。

部署目标为一台约 2 核、2–4GB 内存的服务器，通常不超过 20 人并发。该容量及微信等内置浏览器支持仍需实测。
